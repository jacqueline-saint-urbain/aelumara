# Assets low-poly (Kenney)

Tous les packs 3D de [Kenney](https://kenney.nl/assets/category:3D), licence CC0 (libre, même commercial, sans crédit). Téléchargés le 2026-10-25 pour qu'on choisisse ensuite ce qu'on garde pour Aelúmara. Rien n'est encore utilisé par la page.

Chaque dossier contient `glb/` (modèles prêts pour [Three.js](https://threejs.org/)), `Preview.png` (aperçu du pack) et `License.txt`. Les trois packs de personnages animés sont en FBX seulement.

Quaternius est exclu (3D trop complexe). Seul Kenney est ici pour l'instant : les autres sources de la liste ne sont pas encore téléchargées.
